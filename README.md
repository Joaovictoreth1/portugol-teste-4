# Comparar três números

Exercício de operadores lógicos. `comparar_numeros.por` responde se o primeiro inteiro é menor ou igual aos outros dois. Empates contam como verdadeiros se nenhuma das duas comparações falhar.

## Como executar

No Portugol Studio 2.7.5, abra o arquivo `.por`, execute-o pelo botão ▶ e responda no console quando solicitado.

## Exemplos

| Entrada (`n1`, `n2`, `n3`, em linhas separadas) | Saída |
|---|---|
| `2`, `2`, `3` | `Resultado: verdadeiro` |
| `3`, `3`, `3` | `Resultado: verdadeiro` |
| `3`, `2`, `3` | `Resultado: falso` |
